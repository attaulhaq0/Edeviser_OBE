Scope

This notice covers only the third-party font files listed below, not the
Edeviser application as a whole. Each font retains its applicable copyright,
license, attribution, reserved names and disclaimers. Inclusion does not imply
endorsement of Edeviser by any font author, distributor or licensor.

The listed files are unchanged copies of the pinned published binaries.
Edeviser has not converted, renamed internally, subsetted or otherwise modified
them. Source filenames are retained under src/assets/fonts/. A build may use
content-hashed delivery filenames without changing the font bytes. This public
notice is intended to accompany those assets through Vite's public-file copy
pipeline at /font-licenses.txt.

These provenance checks establish artifact identity, not browser consumption,
visual quality, accessibility benefit, deployment or customer readiness.

of improved reading. Its included faces do not contain Arabic characters.

All paths below are relative to src/assets/fonts/.
All 11 downloads returned HTTP 200. The seven WOFF2 files returned Content-Type
font/woff2; the four WOFF files returned font/woff. Each nonempty file passed
magic (wOF2/wOFF), header-declared length, published byte length and SHA-256
checks. SHA-256 digests matched the base64 digests in the pinned jsDelivr file
manifests, then matched again when the written files were read from disk.
WOFF2 directories were inspected using Brotli decompression and WOFF tables
using their native compression, in memory only; original bytes were retained.

have no fvar axes. This is not a complete font sanitizer or browser decode test.
