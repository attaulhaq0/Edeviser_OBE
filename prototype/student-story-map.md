# Student Story Map

| Screen | Student question | Visual proof | Action | Next screen |
|---|---|---|---|---|
| Dashboard | What should I do next? | Normalization · CLO 3 at 62%, next Assignment 3, Why this? | Review or start assignment | Learning Path / Assignment |
| Learning Path | Where am I? | Level 3 — Apply, 65%, 2 / 5 concepts, +18% | Continue Apply | Assignment |
| Assignment | What evidence am I creating? | CS301, Normalize a Schema, CLO-linked task, Friday deadline | Upload/submit work | Tutor or evidence update |
| Tutor | How does E Deviser help? | Course and outcome context, Guided L2, A1 suggestions only | Ask for guided support | Teacher-handoff proposal when consented |
| Daily Review | What should I reinforce? | Five scheduled cards tied to outcomes | Recall and rate cards | Assignment |
| Progress | What changed? | Mastery, path, habits and evidence confidence | Read the interpretation | Focus / Learning Intelligence |
| Focus | How should I use time? | 25-minute recommendation connected to today’s priority | Start focus session | Review or Assignment |
| Handoff | When does a human enter? | Facts, evidence scope, consent requirement | Share with teacher or not now | Teacher experience |
| Student return | What changed after support? | New evidence is ready to remeasure; no artificial mastery jump | Review the updated next step | Dashboard |

The student story is: Notice → Understand → Learn → Practice → Submit → Evidence → Feedback → Reflect → Improve. Teacher, Parent, Coordinator and Admin consume different authorized views after the Student consent/evidence boundary; this refinement does not modify those role experiences.
