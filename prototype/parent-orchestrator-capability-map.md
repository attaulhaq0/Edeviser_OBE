# Parent Orchestrator Capability Map

## Product-facing orchestration pattern

The Parent prototype represents orchestration as authorized evidence, specialist contributions, a policy/privacy check, a Parent-safe result, and human approval for protected action. It never exposes chain-of-thought or internal model conversations.

| Page | Parent question | Authorized signals | Specialist contribution | Policy result | Output | Autonomy |
| --- | --- | --- | --- | --- | --- | --- |
| Home | What changed and what matters this week? | Course progress, CLO state, Assignment 3, Daily Review, consistency, approved wellbeing context | Mastery + Habit + Intervention + Parent | Verified link; Parent-safe fields; private content excluded | Weekly summary + priority + one support suggestion | A1 Suggest; approval for protected reminders/communication |
| Growth | What is changing over time? | Five courses, CLO 3, Learning Path, 12-day consistency, next evidence | Mastery + Habit + Parent | Parent-safe interpretation | Course progress + current focus + journey + habit trend | A1 Explain; no protected action |
| Support | What can Nadia appropriately do? | Current focus, mastery, assignment deadline, verified relationship | Intervention + Parent | Evidence checked; privacy filtered | One prioritized action + two alternatives + teacher draft | A1 Suggest; A2 Draft only for teacher message |
| Profile | What can E Deviser use for this Parent? | Nadia identity, verified Sarah link, access policy | Parent + Policy | Role-scoped context only | Visible/private fields + assistance settings | A2 Draft only; external communication approval required |

## Interaction and state proof

- “Why am I seeing this?” opens the Home evidence/policy drawer.
- “Why this focus?” opens the Growth specialist/evidence drawer.
- “Why this?” opens the Support rationale drawer.
- “Save for tonight” records a deterministic local prototype state.
- “Review & send” opens a protected communication approval drawer.
- “Send” changes the message status only after Nadia's explicit approval.
- “Edit” returns the approved draft text to the editable message field.
- Escape, backdrop, Cancel, and close controls dismiss drawers and return focus.

## Safety boundary

- No generic chatbot.
- No unrestricted student data.
- No automatic protected action.
- No A3 autonomy.
- No API, database, network integration, or hidden reasoning display.
